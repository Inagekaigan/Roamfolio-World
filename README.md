# Roamfolio

An offline-first travel planner for the web and iPhone. Plan multi-city routes, organize bookings, keep a day-by-day itinerary, and track travel costs across currencies.

## Web

Open `web/index.html` in a modern browser. The city directory, itinerary editor and budget work offline. Photos, nearby places and expanded search require an internet connection. Trips are saved on the device. Use **Documents & notes** to export or restore a trip backup.

## iPhone

Open `ios/Roamfolio.xcodeproj` in Xcode on a Mac. See [the iPhone guide](ios/README.md) for simulator and signing instructions.

The example itinerary is fictional. City and map data sources are credited in the app.
